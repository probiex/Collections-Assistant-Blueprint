---
name: Versioned onboarding state
description: How to evolve the Collections Copilot walkthrough without disrupting existing users.
---

The onboarding completion state is versioned. Keep the current version when changing presentation or minor wording; bump it only when a materially new workflow requires previously onboarded users to see the walkthrough again.

**Why:** Automatically replaying onboarding after every copy or styling update interrupts experienced users, while never replaying it can hide major workflow changes.

**How to apply:** Decide explicitly whether an onboarding change is material. For major navigation or workflow changes, bump the walkthrough version and update the relevant steps together.
